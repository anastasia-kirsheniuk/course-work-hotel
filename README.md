# Курсова робота: Контроль електроспоживання в готелі

**Виконала:** Кіршенюк Анастасія, група АТ-1-1

**Тема:** Система контролю та обліку електроспоживання в готелі

## Що робить система:
- Збирає дані з лічильників електроенергії
- Зберігає в базі даних
- Показує статистику
- Надсилає сповіщення
