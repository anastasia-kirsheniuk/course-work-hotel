## 1. ВСТУП

Метою даної курсової роботи є розробка системи контролю та обліку електроспоживання в готелі на базі IoT-рішення.

Система призначена для:
- Автоматизованого збору даних про споживання електроенергії в номерах готелю
- Ведення архіву показників
- Формування статистичних звітів
- Сповіщення персоналу про критичні ситуації

**Об'єкт контролю:** Готельний комплекс  
**Предмет контролю:** Споживання електроенергії (кВт·год)  
**Технічний засіб аналізу:** Лічильник електроенергії з цифровим виходом  
**Протокол передачі даних:** MQTT  
**Статистика:** Загальна спожита енергія, максимальне та середнє споживання (погодинно)

## 2. РОЗРОБКА ВИМОГ ДО СИСТЕМИ ТА ПЗ

### 2.1. Загальний опис системи

Система складається з:

**Edge-рівень (локальний):**
- Raspberry Pi 4 — центральний контролер
- Лічильники електроенергії з імпульсним виходом
- Локальна база даних MariaDB
- Node-RED для обробки даних

**Cloud-рівень (хмарний):**
- MQTT брокер
- Хмарне сховище (Google Sheets або PostgreSQL)
- Telegram-бот для сповіщень

### 2.2. Функціональні вимоги

1. Зчитування показань з лічильників кожні 10 секунд
2. Збереження даних в локальній БД
3. Передача даних в хмару через MQTT
4. Веб-інтерфейс з:
   - Поточним споживанням по номерах
   - Графіками за добу
   - Історією показників
5. Сповіщення в Telegram при:
   - Перевищенні добового ліміту (>50 кВт·год)
   - Різкому стрибку споживання (>10 кВт за годину)

### 2.3. Апаратне забезпечення

| Компонент | Кількість |
|-----------|-----------|
| Raspberry Pi 4 Model B | 1 шт. |
| Лічильник електроенергії | 10 шт. |
| Резистор 10kΩ | 10 шт. |
| Блок живлення 5V/3A | 1 шт. |
| microSD карта 16GB | 1 шт. |

## 3. РОЗРОБКА АРХІТЕКТУРИ СИСТЕМ

### 3.1. Технічна структура
Номери готелю (101, 102, 103...)
↓
Лічильники
↓
Raspberry Pi (Edge)
↓
┌────┴────┐
↓         ↓
MariaDB    MQTT Broker
↓         ↓
Dashboard  Cloud (Stats + Telegram)

### 3.2. Схема підключення лічильника
Лічильник          Raspberry Pi
─────────          ───────────
S0+  ───┬──────── GPIO17
│
── 10kΩ ─── 3.3V
S0-  ─────────────── GND
1 імпульс = 0.001 кВт·год

### 3.3. Програмна структура

**Edge-рівень:**
- Node-RED flows (зчитування GPIO, обробка, збереження, MQTT)
- MariaDB (таблиці: rooms, meter_readings, hourly_stats)

**Cloud-рівень:**
- MQTT Broker (Mosquitto)
- PostgreSQL / Google Sheets
- Telegram Bot (Python)

## 4. МЕТОДИКА ПЕРЕВІРКИ ТА ТЕСТУВАННЯ

### 4.1. Тест Edge-рівня

**Тест:** Зчитування імпульсів  
1. Підключити лічильник до GPIO17  
2. Запустити Node-RED  
3. Імітувати імпульси  
4. Перевірити логи  

**Очікуваний результат:** Кожен імпульс фіксується

### 4.2. Тест архівування

**Тест:** Збереження в MariaDB  
1. Відправити тестові дані  
2. Запит: `SELECT * FROM meter_readings ORDER BY timestamp DESC LIMIT 10;`  
3. Перевірити наявність записів

### 4.3. Тест аналітики

**Тест:** Погодинна статистика  
1. Запустити скрипт агрегації  
2. Перевірити таблицю hourly_stats  
3. Порівняти з ручним розрахунком

### 4.4. Тест сповіщень

**Тест:** Telegram-бот  
1. Імітувати перевищення ліміту (>50 кВт·год)  
2. Перевірити Telegram  
3. Повідомлення має бути отримано

## 5. РОЗРОБКА ПРОГРАМНОГО ЗАБЕЗПЕЧЕННЯ

### 5.1. Edge-рівень (Node-RED)

**Встановлення на Raspberry Pi:**

```bash
bash <(curl -sL https://raw.githubusercontent.com/node-red/linux-installers/master/deb/update-nodejs-and-nodered)
sudo systemctl enable nodered.service
sudo systemctl start nodered.service
```

**Встановлення MariaDB:**

```bash
sudo apt update
sudo apt install mariadb-server
sudo mysql_secure_installation
```

**Встановлення MQTT:**

```bash
sudo apt install mosquitto mosquitto-clients
```

### 5.2. Формат даних MQTT

```json
{
  "room_id": "101",
  "timestamp": "2026-08-31T10:30:00Z",
  "kwh_total": 125.456,
  "kwh_hour": 2.34,
  "pulse_count": 125456
}
```

### 5.3. Схема передачі даних
Лічильник → GPIO → Node-RED → [Обробка]
↓
┌───────────┴───────────
↓                       ↓
MariaDB (локально)      MQTT Broker
↓                       ↓
Локальний Dashboard     Cloud Service
↓
Telegram Bot

### 5.4. WEB-інтерфейс

**Локальний (Node-RED Dashboard):**
- URL: `http://<raspberry_pi_ip>:1880/ui`
- Gauge: поточне споживання
- Chart: графік за 24 години
- Table: останні показання

**Глобальний:**
- Google Sheets з автооновленням
- Або Grafana + PostgreSQL
